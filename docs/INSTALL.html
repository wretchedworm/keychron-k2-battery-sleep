Keychron Menu

Your keyboard's battery and auto-sleep switch, at the top of your Mac screen.

Preview release. Apple silicon Mac, macOS 13 or later. Tested on the original non-backlit K2-M1 with Bluetooth firmware 1.08 (20210820). This app is not notarized by Apple.

Install in three steps

  1. Return to the Keychron Menu disk-image window.
  2. Drag KeychronMenu onto Applications.
  3. Open Applications and double-click KeychronMenu. Look for its icon in the menu bar. There is no main window.

If macOS blocks the first launch

After trying to open the app, open System Settings → Privacy & Security. Look for Open Anyway for KeychronMenu. Proceed only if you trust this download. Read Apple's guidance.

Finish setup

Allow notifications for the 20% and 10% battery warnings. If the app reports denied keyboard access, choose Keyboard access settings… in its menu and enable KeychronMenu under Input Monitoring. Quit and reopen it if asked.

Keep the keyboard connected by Bluetooth. Changing auto-sleep briefly reconnects it. Wait for ON or OFF before typing. Eject this disk image when installation is finished.
